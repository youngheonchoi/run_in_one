# run_in_one

러닝 정보를 한곳에서 관리하는 올인원 서비스의 MVP입니다. 모바일 우선으로 대시보드와 페이스 계산기를 제공합니다.

Next.js App Router 기반의 단일 앱으로 구성되어 있습니다 (`http://localhost:3000`).

MVP 기능:

- 대시보드: 주간 요약, 거리 차트, 목표 진행률, 최근 러닝
- 페이스 계산기: 거리·시간 입력, 평균 페이스, 풀코스 예상 기록

## 시작하기

```bash
npm install
npm run dev:next
```

## 검증

```bash
npm run build
npm run lint
```
